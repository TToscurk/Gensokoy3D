# 幻想鄉 3D — Gensokyo Explorer

可自由行走、飛行、與角色對話的 3D 幻想鄉。純 Web（WebGL2 / three.js），
所有角色模型與特效貼圖都在執行時程序式生成；地表與建築貼圖採雙軌制——
優先使用 `assets/textures/` 裡的 CC0 PBR 照片素材（Poly Haven），
檔案缺席時自動退回 canvas 程序貼圖，專案永遠可獨立執行。

## 啟動

雙擊 `run.bat`，或手動：

```bash
python -m http.server 8080
```

然後開 <http://localhost:8080/>。

> ES module 不能用 `file://` 直接開啟，一定要經過 HTTP 伺服器。
> three.js 已打包在 `vendor/three/` 本機提供，完全離線可玩。

## 操作

| 按鍵 | 功能 |
|------|------|
| `WASD` | 移動 |
| `Shift` | 疾走（飛行時加速） |
| `Space` | 跳躍；飛行時上升 |
| `Ctrl` / `C` | 飛行時下降 |
| `F` | 切換飛行（繼國緣一不會飛，改為二段跳） |
| `E` / 左鍵 | 與附近角色對話、推進對話 |
| `滑鼠` | 轉動視角（點擊畫面鎖定游標） |
| `滾輪` | 拉近／拉遠 |
| `Esc` | 放開游標 |
| `O` | 設定面板（畫質、時刻、FOV、滑鼠、傳送） |
| `J` | 任務日誌面板 |

視角預設為順向：滑鼠往右視角往右，滑鼠往下視角往下。
設定面板可調靈敏度，或把 Y 軸切成反轉。

## 十七個地區

博麗神社、人間之里、魔法之森、霧之湖、紅魔館、迷途竹林（永遠亭）、白玉樓、
守矢神社、命蓮寺、香霖堂、無緣塚、無名之丘、太陽花田、妖怪之山、天狗聚落、
天界、彼岸。
地形以雜訊生成，每個地區會把地表壓平成適合建築的台地，
彼此之間用自然起伏銜接。設定面板可直接傳送。白玉樓、天界、彼岸屬於
「結界之外」的遠方地區，傳送時會有黑幕＋進度條的過渡動畫；其餘地區近距離
即時傳送。

有建築的地區：博麗神社（依 THBWiki 考據重建的入母屋造拜殿＋大鳥居＋長石段
參道）、人間之里（十字街廓＋町屋＋鈴奈庵＋寺子屋＋市集）、紅魔館（可走進去
的正廳）、白玉樓、魔法之森（魔理沙邸）、永遠亭（長屋三棟）、守矢神社（御柱
四方）、命蓮寺（山門＋三重塔）、香霖堂（古道具店）、無緣塚（石塔群與地藏）、
太陽花田（涼亭）、天狗聚落（妖怪之山山腰，含瀑布）、天界（雲上白石台地）。

## 三十四位角色

靈夢、魔理沙、咲夜、美鈴、蕾米莉亞、帕秋莉、芙蘭朵露、琪露諾、大妖精、
妖夢、幽幽子、慧音、鈴仙、露米婭、紫、輝夜、永琳、妹紅、早苗、神奈子、
諏訪子、白蓮、幽香、霖之助、文、比那名居天子、小野塚小町、四季映姫、
阿福婆、小豆、霍青娥、宮子、向日葵妖精，以及異世界來客**繼國緣一**。

每位角色有 4～7 組對話，重複交談會輪替。所有角色都有一組談論緣一的對話——
他的存在被人從史書上抹去，而幻想鄉正是收容「被外界遺忘之物」的地方。

可操作角色：靈夢、魔理沙、咲夜、妖夢、早苗、繼國緣一、外來人（移動速度各異）。
其中緣一是人類劍士，不會飛，改以二段跳移動。

超過 260m 的 NPC 會整隻隱藏並停掉待機動畫（距離剔除），
所以 34 位住民同屏的負擔跟角色數少得多的時代相去不遠。

## 任務系統

手寫分支任務樹（非 LLM API）：`src/quests/data.js` 只放資料（節點＋
`onTalkTo` / `onEnter` / `branch` 三種邊），`src/quests/manager.js` 是不認識
任何任務內容的引擎。跟 NPC 對話或走進特定地區會自動推進，`J` 鍵開任務日誌，
toast 通知開始／更新／完成，進度存在 `localStorage`，重整頁面不會不見。
內建三個範例任務：`erased_records`（找繼國緣一，依晝夜走向不同分支後收斂）、
`shrine_pilgrimage`（三神社巡禮）、`missing_curio`（香霖堂遺失物）。

## 技術筆記

幾個為了在 1070 上穩住 60fps 而做的決定：

**Draw call 才是瓶頸，不是三角形。** 初版每幀 846 個 draw call，其中 776 個來自角色
（每個角色約 48 個網格，含描邊外殼）、764 個來自建築。建築完全靜態，因此把世界矩陣
烘進頂點後依材質合併（`core/optimize.js`）；角色則以「動畫節點」為單位合併，
各部位的材質顏色烘成頂點色，讓十六個角色共用同一份 toon 材質。
最後降到 **137 個 draw call**。

**描邊用法線外推，不是等比放大。** 等比放大在細長物件（手腳、刀）上的描邊厚度會失真，
沿頂點法線位移才是正確的反向外殼做法。

**草跟著玩家走。** 把固定預算平均撒滿 1700×1700 的世界等於每 100 平方公尺一撮草。
改成維持一塊以玩家為中心的 8×8 磚格，跨過磚界時每幀最多重建 2 塊
（`GrassField`），同樣的 instance 數量密度提高兩個數量級。

**梯度雜訊查表。** `terrainHeight()` 是全專案呼叫最頻繁的函式（地形網格、植被落點、
玩家碰撞、相機、草地磚塊）。原本每個角點用 `cos`/`sin` 算梯度方向，一次呼叫將近
90 次三角函數；改成 32 方向查表後大幅下降。

**花瓣不每幀取樣地形。** 落地高度在重生時算一次存起來。原本 1600 片花瓣每幀各呼叫一次
`terrainHeight`，光這一項就吃掉 5.3ms —— 整幀預算的三分之一。

**燈籠光源池。** 場景有上百盞燈籠，但 WebGL 的 uniform 數量有限。維持 8 盞
`PointLight` 的池子，每 0.25 秒指派給離玩家最近的幾盞，夜裡才點亮。

**GTAO 是「引擎感」最大的單一來源。** 接觸陰影讓牆角、樹根、屋簷下沉，
後製鏈改為 Render → GTAO → Bloom → 色彩分級 → SMAA。色彩分級是固定的
電影調：飽和微推、暗部偏青、亮部偏暖、四角輕暗角，成本約 0.2ms。

**雲與霧各只要一個 draw call。** 自寫 shader 的 instanced 面片：雲用圓柱式
billboard 緩慢橫越天空、邊緣淡出；霧片平貼地面，在湖面／魔法之森／竹林／
無緣塚／冥界漂移呼吸，清晨與夜晚最濃（`fx/atmosphere.js`）。

**地形是六層 splat 混合。** 每個頂點帶一組權重（草地／森林落葉／岩石／土路／
沙／雪），依地區、坡度、高度、湖岸距離在建構時算好；fragment shader 依權重
混六套 CC0 PBR 貼圖的反照率與法線，再用頂點色做宏觀色調（正規化成相對於
各層平均色的比值，貼圖管細節、頂點色管地區變化，兩者不會疊加倍暗）。
法線貼圖在 90m 外淡出，避免高頻平鋪的摩爾紋。

**貼圖雙軌制與熱替換。** 材質建構先用 canvas 程序備援版，`TextureLoader`
載入完成後直接替換同一個 Texture 物件的 `image`——所有引用它的材質
不需要任何通知就自動換上照片素材；檔案不存在時則永久停在程序版。

**草地有兩種長相、而且跟著地表染色。** 草葉圖集左半是修長高草、右半是
寬葉矮叢，每個實例用 instanced 屬性挑邊；實例顏色取樣 `biomeColor`，
森林裡的草偏深、神社周邊偏乾、湖岸偏黃，和腳下的 splat 地形互相呼應。

**樹皮是真的。** 一般樹用日本杉皮、櫻花樹用櫻皮（皆含法線貼圖）；
魔法之森的扭曲暗樹刻意保留程序深色皮——被魔法浸過的感覺照片做不出來。

**村子一眼就有貧富與年代。** 民家逐戶隨機搭配「白灰泥牆／風化木板牆」
×「瓦頂／茅草頂／黑瓦」，中央廣場鋪石板，市集攤位用木地板檯面。

**風吹整片世界。** 樹冠、竹葉、向日葵、鈴蘭的 instanced 材質注入同一段
`onBeforeCompile` 風擺 shader，頂點越高擺幅越大，全部共享一個時間 uniform。

**角色三階賽璐璐 + 輪廓光。** 色階從 4 階改成 3 階，色塊更乾淨；
共用卡通材質注入 fresnel rim light，顏色每幀跟著日光色溫走——
逆光時角色邊緣會亮，這是動畫感的關鍵，成本接近零。

**移動基底必須用相機的「前方」，不是「方位」。** `camYaw` 描述的是相機相對角色的
方位，水平前方是 `-dir` 而非 `+dir`。少了那組負號時，`camYaw = 0` 剛好正確，
所以很容易漏掉 —— 但視角一轉，WASD 就會相對視線鏡像，轉到 90 度時 W 直接往後走。

**解除飛行要收斂水平速度。** 飛行速度是步行的三倍，直接切回地面模式會帶著慣性
滑出去。`_endFlight()` 把水平速度壓回步行區間。

最終（2026-07-24 第三輪實測，高畫質，出生點視角）：60fps，310 draw call，
約 578 萬三角形，65 張 GPU 貼圖，console 零錯誤。三輪擴充下來 draw call
從初版 137 一路漲到現在的 310，主因是角色數（16→34）與建築複雜度持續增加；
60fps 仍然達標，但這條線已經拉得夠長，之後每加東西建議先跑
`.tmp/e2e_check.mjs` 量測再動手。

## 檔案結構

```
src/
  config.js            畫質預設、世界尺度、十七個地區定義
  core/
    noise.js           梯度雜訊、fbm、可重現亂數
    textures.js        程序貼圖 + 檔案貼圖載入器（熱替換、程序備援）
    optimize.js        靜態合併、動畫節點合併、描邊外殼
  world/
    terrain.js         高度場（全專案共用的唯一真相）、生態著色、六層 splat
    vegetation.js      instanced 樹木／竹林、GrassField、除草區登記
    water.js           霧之湖
    structures.js      神社、村落、紅魔館、白玉樓、竹林
    sky.js             大氣散射天空、晝夜循環、星空
  entities/
    model.js           程序式角色建模、卡通著色、待機動畫
    roster.js          三十四位角色的外觀與對話
    npc.js             NPC 生成、名牌、互動偵測
  player/controller.js 第三人稱控制、飛行、碰撞、可走平台
  quests/
    data.js            任務資料（純資料，stages + onTalkTo/onEnter/branch）
    manager.js         任務引擎，不認識任務內容
  fx/
    postprocess.js     Bloom、SMAA、色調映射
    particles.js       櫻花、人魂、彈幕
    atmosphere.js      雲與霧（instanced 面片 shader）
  ui/
    dialogue.js        對話框
    questlog.js        任務日誌面板、toast 通知
  main.js              組裝與主迴圈、遠方地區傳送過渡
```

## 除錯

主控台有 `__gensokyo` 可直接操作場景：

```js
__gensokyo.sky.time = 1150      // 切到黃昏
__gensokyo.sky.speed = 0        // 凍結時間
__gensokyo.player.pos.set(0, 60, 380)
__gensokyo.renderer.info.render  // draw call / 三角形
```

## 授權與素材

[Poly Haven](https://polyhaven.com)，全部採 **CC0**（公眾領域）授權，
可自由使用於任何用途；清單與來源見 `assets/textures/manifest.json`。
其餘角色模型、特效貼圖、地形皆為執行時程序式生成。
